# 🏗 NK Construction Portfolio Website

A modern, responsive web application built to showcase NK Construction’s projects, services, and company profile. This project demonstrates the evolution from a static portfolio into a scalable, full-stack solution.

---

## 📌 Project Overview

NK Construction previously relied on non-interactive methods to present its work, which limited its ability to attract and engage potential clients.

This project transforms that approach into a **professional, web-based platform** that:

* Showcases completed projects
* Clearly communicates services
* Improves brand credibility
* Enhances accessibility across devices

## 🧠 Key Engineering Decisions

* Started with **Bootstrap + PHP** for rapid delivery
* Used **Tailwind CSS** for flexible custom styling
* Chose **Netlify** for simple deployment and fast hosting
* Planning migration to **Next.js** for performance and scalability
* Introducing **Payload CMS** for dynamic content and admin control

---

## 🔄 Migration Strategy

The project is being upgraded in phases:

1. Rebuild frontend using Next.js
2. Integrate Payload CMS
3. Migrate static content into CMS
4. Implement authentication and uploads
